# Omnifood - static meal subscription website 
Omnifood is a modern AI-powered meal subscription website that suggests personalized, healthy meal plans. It’s built with HTML, CSS, and JavaScript, emphasizing responsive design, interactivity, and clean user experience.

## what i got from building this?
By exploring this project, you’ll see how I combine design precision with real-world front-end development skills. It demonstrates my ability to craft responsive layouts, manage structured content, and enhance user engagement through animations and dynamic interactions. This project also showcases how I translate a product idea into a functional, visually polished website—highlighting my strength in building professional, scalable, and user-centered digital experiences.
